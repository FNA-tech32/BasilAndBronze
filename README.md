# Basil&Bronze

Basil&Bronze is a static, responsive website for an Italian restaurant in Soho, London. It is a single page built with HTML, CSS, and JavaScript, and it opens directly in a browser with no build step.

## Sections

- **Home** — hero carousel with the restaurant name and links to the menu and table booking
- **About** — a short history and the dishes the kitchen is known for
- **Menu** — starters, salads, pasta, and drinks
- **Events** — birthday parties, holiday gatherings, and private events
- **Gallery** — photos from the restaurant
- **Book a table** — a reservation form
- **Contact** — map, address, opening hours, email, phone, and a message form

## Open the site

Open `index.html` in a browser.

## Libraries

- Bootstrap 5
- Bootstrap Icons
- Boxicons
- Swiper
- Isotope
- Animate.css
